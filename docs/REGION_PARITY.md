# 横浜・湘南の機能差（2026-10-11 調査）と統一の方針

調べ方：index.html の地域分岐（`SH.inShonan`・`regionAt()==='shonan'`・`inWorld`・`WORLD.*`・`SH.*`）を全部追い、両地域で同じ操作をヘッドレス Chromium で実行（tools/smoke）。

## 統一の方針
- **地図は地域ごとのデータ、処理は共通**：湘南も横浜と同じパイプライン（tools/gsi/fetch_tiles.py → build_world.py）で `data/world/shonan-*` を作り、`WORLD` を「複数地域の地図をまとめる窓口」にする。陸・道路・建物・橋・防波堤・道路網・交通・ミニマップ・海岸の泡は全地域で同じ関数。
- **地域固有のものはデータで持つ**：釣り場（位置・種類・規制）・駅と路線・名所・魚の出現。
- **これから足す地域**（横須賀・小田原・箱根など）は、world データを作る or 関東の近景エンジン（kanto.js）で同じ機能が動く。

## 統一の結果（2026-10-11）
- `data/world/shonan-base.js`・`shonan-bld/`：湘南（大磯〜鎌倉、geo.js の湘南の枠）を横浜と同じパイプラインで作成（タイル848枚、建物26万棟・道路3.6万本・防波堤227・駅と地名）。PLATEAU は湘南の市町の公開データが取得できる場所に無く、建物の高さは横浜と同じ推定式（未取得の項目）。
- `world.js` の `combine`：複数地域を1つの `WORLD` にまとめる（点は含む地域へ、範囲は合わせる、経路の道路網は1地域の中）。index.html の陸・歩行・地面の高さ・建物・道路・設備・橋・海岸の泡・交通（NPC）・車の道・駐車場の推定・ミニマップは全地域で同じ関数。
- 湘南の釣り場：手描きの海岸線は平塚・大磯で約400m 沖にずれていたため、実在の水際へ（最大900m 探す）。堤防の釣り場は近くの歩ける防波堤の上。駅は国土地理院の同じ名前の駅の位置、バス停は近くの釣り場の近くの車道。
- 共通の新機能：防波堤（漁港・堤防の釣り場の近く）を歩ける、外海の砂浜（砂浜の釣り場の近く、磯・漁港・江の島は除く）と波打ち際の濡れた砂、丘の木（標高8m 超・建物と道路の無い所）。
- 古いセーブ：mapv 4。歩けない位置で再開したら近くの歩ける所 → 同じ地域の駅へ。海や建物の中になった湘南の駐車中の乗り物は近くの駐車場へ。
- 確認：tools/smoke/scenarios/parity.mjs（横浜・本牧、湘南・平塚新港、湘南・片瀬西浜で同じ操作：歩行・釣り場・投げて巻く→アタリ・釣具の購入・地面の種類・NPC・駅から移動・ミニマップ・ワールドマップ・セーブ）。

## 地域固有のまま（仕様）
釣り場の位置と規制（湘南の規制エリア・利用時間、横浜市の方針）、駅と路線（湘南は JR・江ノ電・小田急）、名所、魚の出現の重み、湘南の釣り場の種類ごとの環境（波・流れ・底質）。

## 未完了だった項目（2026-10-11 対応）
- ジャンプ・段差：済。地域共通（足元の高さ PY・0.45m までの段差は歩いて上れる・ジャンプ約0.9m・落下）。PC はスペース（釣り場以外）、スマホは「ジャンプ」ボタン。確認：tools/smoke/scenarios/common.mjs。
- 魚市場・売却：済（Phase 11 の土台）。market.js。釣った魚は持ち物（クーラー／バケツ5kg）へ、買取所7か所（横浜2・湘南5、実在の市場・漁港の住所の近く。ゲーム上の設定）で売る。値段＝基準単価×重さ×大きさ×鮮度×その日の相場×店の種類。車の魚の出し入れ。古いセーブのクーラーの重さは「以前の買取済み」として残る。
- 湘南の名所の模型：済。シーキャンドル（らせんの鉄骨・展望台・地上約60m）、大仏（台座・定印の手・肉髻）、鶴岡八幡宮（大石段・二層の楼門・舞殿・大鳥居）。実在の江の島の上に作り物の丘を重ねていた不具合と、島を歩けなくしていた当たり判定を外した。
- 湘南の PLATEAU：**取得できない**（G空間情報センターの公開バケットに湘南の市町のデータが無い。横浜・横須賀のみ）。建物の高さは国土地理院の建物の種類と面積からの推定のまま。公開されたら tools/plateau/fetch_heights.py に追加して build_world.py で反映できる。
- 実機（スマホ）での確認：こちらではできない（ユーザーの確認待ち）。
- 新しい地域の追加手順：`python3 tools/gsi/fetch_tiles.py <名前> <lat0,lon0,lat1,lon1>` → `python3 tools/gsi/build_world.py <名前>` → index.html に `data/world/<名前>-base.js` の script を足し、WORLD の地域名の一覧に足す。釣り場・駅・買取所はデータで足す（market.js の PLACES は緯度経度なので、どの地域でもそのまま置ける）。world データが無い所も関東の近景エンジン（kanto.js）で地形・建物・道路・駅が出る。
